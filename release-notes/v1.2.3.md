## What's new in 1.2.3

- Added a compact Home menu with Settings, Check for updates, and Clear all data.
- Moved the dark mode switch into Settings and added the installed app version there.
- Added a left swipe on unfinished jobs to request deletion, with a confirmation before the saved draft is removed.
- Added a confirmed Clear all data action that resets JobTracker's jobs, drafts, photos, private costs, settings, and permissions on this phone. Copies exported elsewhere remain.
